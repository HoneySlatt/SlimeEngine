# 0179. The framework named uwui

- Status: Accepted; amends [0178](0178-two-pilots-and-the-frameworks-name.md) (the framework's
  name)
- Date: 2026-11-05

## Context

[ADR-0178](0178-two-pilots-and-the-frameworks-name.md) named the engine's UI framework lumui, its
crates to be renamed in milestone M6c.N. No crate had been renamed when the owner chose another
name, the same day.

## Decision

**The framework is named uwui.** M6c.N renames `slime-ui` to `uwui` and `slime-ui-render` to
`uwui-render`; in prose, the framework is uwui. The name was free on crates.io on 2026-11-05.
Everything else that ADR-0178 decides stands.

## Alternatives considered

- **lumui**, as ADR-0178 decided: a name of light and glass, read as serious; the owner preferred
  a name of more character, which people remember.

## Consequences

- The documents that named lumui name uwui; ADR-0178 keeps the name of its date.
